# Privacy Shield v3

تطبيق تجريبي لأندرويد بصلاحية Root. عند اكتشاف وجهين أو أكثر بالكاميرا الأمامية يفعّل Extra Dim وتدرّج الرمادي، وعند ثبات وجه واحد يستعيد الإعدادات.

## الجديد في v3
- مربع في الإعدادات السريعة (Quick Settings) لتفعيل/إيقاف الحماية يدوياً.
- زر "تفعيل / إيقاف الحماية يدوياً" داخل التطبيق.
- استرجاع تلقائي لإعدادات الشاشة بعد إعادة تشغيل الهاتف إن بقيت الحماية مفعّلة.
- ملف GitHub Actions لبناء APK على سيرفرات GitHub بدون Android Studio محلياً.

## الجديد في v2
- شريط لضبط شدة التعتيم ومفتاح للرمادي (يُحفظان).
- حفظ الإعدادات الأصلية على القرص واسترجاعها تلقائياً عند فتح التطبيق إن أُغلق بشكل غير طبيعي، مع زر "استعادة إعدادات الشاشة الآن".
- إيقاف الكاميرا عند إطفاء الشاشة وتحليل بدقة 640x480 لتوفير البطارية.
- زر "إيقاف" داخل إشعار الخدمة، وعرض حي لحالة المراقبة والحماية.
- إصلاح opt-in لـ ExperimentalGetImage الذي قد يفشل في فحص lint.
- إضافة gradle.properties (AndroidX) وgradle-wrapper.properties.

## حدود مهمة
- لا يحوّل S25 إلى Privacy Display حقيقي؛ لا يمكن للبرنامج تغيير اتجاه انبعاث الضوء.
- لا تعتمد عليه لإخفاء معلومات حساسة.
- مفاتيح الإعدادات لم تُختبر على أندرويد 17؛ جرّب زر الاختبار أولاً.
- المعالجة محلية عبر ML Kit ولا تُرسل صور لأي خادم.

## البناء
1. افتح مجلد `PrivacyShield` (فيه settings.gradle.kts) في Android Studio.
2. JDK 17 + Android SDK Platform 35، وانتظر Gradle Sync (يحتاج إنترنت).
3. شغّل على الهاتف عبر ▶ أو Build > Build APK(s).
